# Conway Topograph

Rust / egui による、コンウェイのトポグラフを手動で描くためのデスクトップGUIです。
各ノードに接続できる辺を最大3本に制限します。領域の数値や二次形式の計算は実装していません。

## 起動

Rust 1.95 以降と、ウィンドウを表示できるデスクトップ環境が必要です。

```sh
cd /home/tsubaki/work/rs/conway-topograph
cargo run --release
```

## 操作

| 操作 | 動作 |
| --- | --- |
| 空白を左クリック | ノードが0個のときだけ最初のノードを追加 |
| ノードを左クリック → 別のノードを左クリック | 2つのノード間に辺を追加 |
| ノードを左クリック → 空白を左クリック | 新しいノードを追加し、そこまで辺を接続 |
| Shiftを押しながら終点を左クリック | 接続後、その終点を次の始点として連続して延ばす |
| ノードが0個のときにShift＋空白を左クリック | 最初のノードを追加し、そのノードから接続を開始 |
| 辺を左クリック | 通常の線と2重線を切り替え |
| Ctrlを押しながら2つのノードを順に左クリック | 間の経路の辺をまとめて1重・2重に切り替え |
| ノードを右クリック | ノードと接続する辺を削除（Undoで復元可能） |
| Esc / ノード以外を右クリック / Cancel selection | 接続待ち・経路選択をキャンセル |
| ノードを左ドラッグ | ノードを移動 |
| 空白を左ドラッグ | キャンバスを移動（ノードは追加しません） |
| マウスホイール | カーソルを中心に拡大・縮小（25%〜3000%、現在の倍率はZoomに表示） |
| マウス中ボタンでドラッグ | キャンバスを移動 |
| Reset view | 表示倍率と移動をリセット |
| Undo / Ctrl+Z（macOSではCmd+Z） | 直前の変更を取り消し（最大100回） |
| Clear | 全消去（Undoで復元可能） |
| View: Editor / Black & white | 通常表示と白黒表示を切り替え |
| Export CeTZ | Typst用のCeTZソースを保存・コピー |
| Background image | 背景画像を指定・調整 |

ノード内は通し番号、下の `n/3` は接続済みの辺の数です。3本に達すると枠が琥珀色になります。
ノード削除時は接続待ちを解除し、残ったノードの番号を詰め直します。残った辺の2重線設定は保持します。
同じノードに接続する2本の辺のなす角（小さい側）が90度以下の場合、その2本を赤色で表示します。
ノードの移動・辺の追加削除で自動更新し、90度を超えると元の色に戻ります。
両ビュー・2重線に対応します。長さ0の辺は角度を定義できないため判定対象外です。
この色は編集画面の目印で、CeTZ出力は従来どおり黒色です。
自己ループと重複辺は禁止です。接続できない終点を選ぶと理由を表示し、別の終点を選べます。
ノードがすでにある場合、始点を選択していない状態で空白をクリックしても追加しません（Shift中も同様）。
既存ノードをクリックして始点にすると、空白に新しい終点を追加できます。
Shiftを押したまま空白を順にクリックすると、接続待ちのノードからノードと辺を鎖状に追加できます。
Shiftを押したままでもホイールで拡大・縮小でき、接続待ちは維持されます。
Shiftを離して次の終点をクリックすると接続を確定して終了します。Escでも接続待ちを解除できます。
既存ノードを終点にした場合もShiftで続けられますが、接続後に辺が3本となるノードでは終了します。
2重線は1本の辺の表示方法なので、接続数は増えません。両ビューに対応し、Undo・自動保存にも反映されます。
辺の端ではノードのクリックを優先するため、切り替えは辺の中央付近をクリックしてください。
Ctrlによる経路選択は、辺の本数が最少の経路を対象にします。同じ長さの経路が複数ある場合は辺の作成順で決まります。
対象の辺がすべて2重なら1重に戻し、1重が含まれていればすべて2重に統一します。分岐先の辺は変更しません。
接続されていないノードを選ぶと理由を表示し、別の終点を選べます。同じノードを2回選んでも変更しません。
操作全体を1回のUndoで戻せます。Ctrlを離して通常のクリックをすると経路選択を終了して通常操作に戻ります。
両ビューで利用でき、最初のノードは選択枠で示します。macOSでもこの操作にはControlキーを使用します。

`Black & white` ではキャンバスが白、辺が黒、ノードが小さな黒い点になり、番号・接続数・枠を非表示にします。
どちらのビューでも追加・接続・移動が可能です。切り替えても図や表示位置は変わりません。
空白から始めたドラッグはノードを通過してもキャンバス移動のままです。接続待ちでも移動できます。

図はeframeのアプリ用保存領域に定期的および正常終了時に自動保存し、次回起動時に復元します。
Linuxでは通常 `$XDG_DATA_HOME/conwaytopograph`（未設定なら `~/.local/share/conwaytopograph`）です。
ビューの選択・表示倍率・パン位置とUndo履歴は保存しません。GUI内の表示は英語です。

## 背景画像

`Background image` で画像のパスを入力し、`Load image` を押してください。
画像ファイルをウィンドウにドラッグ＆ドロップしても読み込めます。
PNG / JPEG / WebP / GIF / BMPに対応します（アニメーションは静止画として読み込みます）。

- `Show background`：表示・非表示
- `Opacity`：不透明度
- `Image scale`：画像の大きさ（縦横比を保持）
- `Position` のX・Y：画像の左上位置（右・下が正方向）
- `Remove image`：背景の指定を解除

画像はノード・辺の背面に表示され、キャンバスのパン・ズームに追従します。
画像上でも同じ操作で、最初のノードや辺の終点を追加できます。
背景画像はEditorでのみ表示し、Black & whiteでは非表示にします。
Editorに戻すと、保存された表示設定に従って再表示します。
新しい画像は図の座標原点に配置し、800×600以内に収まる大きさで読み込みます。
画像のパスと表示設定は自動保存し、次回起動時に再読み込みします。画像ファイル自体は埋め込まないため、元の場所に残してください。
背景の調整は図のUndo対象外です。CeTZへの書き出しには背景画像を含めません。

## Typst / CeTZへの書き出し

1. `Export CeTZ` をクリックします。
2. 保存先を入力して `Save` をクリックします。初期値は起動ディレクトリの `topograph.typ` です。
   絶対パスも指定でき、拡張子を省略すると `.typ` が付きます。既存ファイルを指定するとボタンに上書きと表示します。
3. Typst文書から読み込みます（文書と同じ場所に保存した場合）。

```typst
#include "topograph.typ"
```

サイズを指定する場合は、代わりに関数をインポートします。

```typst
#import "topograph.typ": topograph
#topograph(unit: 2cm)
```

初期値はエディタの100座標単位が1cmです。`unit: 2cm` なら座標と点の半径が2倍になります。
線幅は出力ソース内の `0.7pt` で変更できます。`Copy CeTZ` でソース全体をクリップボードへコピーすることもできます。

書き出しは常に黒い辺と黒い点で、2重線を反映します。ノード番号・接続数・背景は出力せず、
画面外を含む図全体を出力します。ズームやパン位置は出力に影響しません。
Typstの上向きのY軸に合わせて座標を変換するため、上下関係は画面と同じになります。

出力ファイルはCeTZ 0.5.2をインポートします（Typst 0.14以降が必要）。
初回のTypstコンパイルにはパッケージ取得のためネットワーク接続が必要です（キャッシュがあれば不要）。
構文の参考：[CeTZの基本構文](https://cetz-package.github.io/docs/getting-started/)、
[line](https://cetz-package.github.io/docs/api/draw-functions/shapes/line/)、
[circle](https://cetz-package.github.io/docs/api/draw-functions/shapes/circle/)。

```sh
cargo test

```
