# 数学モデルと判定条件

## 厳密な組合せ構造

面は原始整数ベクトルの符号同値類 [p,q]。q>0（q=0 のとき p>0）を代表に取る。
面は木の頂点ではない。木の頂点は lax superbase に対応し、Farey の理想三角形の3つの有理境界点 p/q と同一視する。
辺は隣り合う2つの面 u,v（|det(u,v)|=1）を共有する2頂点を結ぶ。
その両端の第三面は [u+v] と [u-v]。符号正規化した各代表の和・差から候補を作り、現在と異なる候補に反転する。
木の根は { [1,0], [0,1], [1,1] }。
ラベルは常に a p² + b p q + c q² を BigInt で直接評価する。
2Q(u)+2Q(v)-Q(w) による伝播との一致を検証する。

## 3面による係数復元

各行 (p²,pq,q²) の3×3整数行列に Cramer の公式を適用する。
行列式ゼロなら非一意、各分子が分母で割り切れなければ非整数係数として拒否する。
初期3面のラベル A,C,S は a=A, c=C, b=S-A-C。
任意面の編集は3固定面の制約を通して行い、他の2面を黙って変更しない。

## Ascent / descent と井戸

Milea–Shelley–Weissman の Conway climbing principle と Hatcher §4.1–4.3 を参照する。
辺の共有面値を U,V、現在頂点の反対面値を W、隣接頂点の反対面値を W' とすると
W'=2(U+V)-W。W, U+V, W' は等差数列となる。
正定値の場合、外向き ascent の符号は W'-W の符号。
3方向すべて W'-W>0 なら単一頂点の井戸。
すべて >=0 で1方向が0ならその無向辺と両端頂点を合わせた二重井戸。
正定値では2方向以上が0にはならない。
負定値の場合は -Q に同じ規則を適用する。したがって Q そのものには3方向の下降が出る。
井戸のUIには3つの値と W'-W を表示する。最小の面を選ぶ方法ではない。
例 x²+y², x²+2y² は初期辺の b=0 に対応する二重井戸。
例 x²+xy+y² は単一井戸。

## 川と湖

D>0 を不定値と分類する。辺の共有面の値がいずれも非零で、符号が異なるとき、その辺を川（separator）とする。
D が非平方なら整数の原始零ベクトルは存在せず、separator は無限の川となる。
D>0 が平方なら2つの異なる有理零方向（湖）があり、separator はその湖を結ぶ有限経路となり得る。
2湖が隣接すると、その間のseparatorは長さ0（例 xy）となる。
x²-y² の2湖 [1,1] と [-1,1] は行列式の絶対値が2で非隣接。その間には共有面 [1,0], [0,1] のseparatorが1辺ある。
D=0 の非零形式は半定値であり、有理核に対応する1湖がある。零形式ではすべての面が湖。
湖は Q(p,q)=0 の面領域そのものとし、頂点・辺の零判定で代用しない。
表示中の有限の面領域パッチを水色で塗る。無限の全面領域を生成しない。

## 双曲幾何

Cayley φ(z)=(z-i)/(z+i)、φ⁻¹(w)=i(1+w)/(1-w)。
標準 Farey 三角形 (∞,0,1) の内心は z₀=(1+i√3)/2。
任意三角形について、det(u,v)=1 の符号付き整数基底を選び第三面が [u+v] になるようにする。
行列 M=(u v) の作用 M(z)=(pᵤz+pᵥ)/(qᵤz+qᵥ) が標準三角形をその三角形へ写すので M(z₀) を内心とする。
座標は浮動小数点に限る。高精度整数の上位ビットを共通スケールに変換してから複素除算する。
等長変換により内心と測地線は保存される。隣り合う内心間の測地線は共有 Farey 辺と直交する。
線分の描画点は片方の端を原点に送る円板自己同型を使い、直径上の点を逆変換して得る。
したがって描画点は正しい測地線円弧上にあり、Euclid 直線で端点を結ぶ近似ではない。
描画用の曲線分割のみ画素精度の有限近似。
面パッチは内心・隣接内心との双曲中点・その面の理想境界点を結んだ領域。
これは双対木の補集合の一部であり、ラベル位置とクリック判定はこの領域に置く。

実装の式は上の定義から導出したもの。特定の形式全体の周期や Pell 方程式の基本解の計算は本実装の範囲外。

正確な Farey 双対木では、PSL₂(Z) の対称性から隣接内心の双曲距離は実際に ln(3) で一定になる。
この実装は有理境界点・整数行列・内心からその性質を導出し、テストする。画面上の Euclid 長は視点と位置で変化する。
表示深さは初期根からの全域深さではなく、現在の整数局所基底の根から測る。

## 値による面の配色

配色モードでは、正の値を赤、負の値を青とし、明るさ I(q)=s/(s+|q|) を用いる（s は Color scale、1〜1000000）。
q が零に近づくと I は1、|q| が無限大に向かうと I は0。|q|=s で明るさが半分になる。
RGBの明るいチャネルを round(255s/(s+|q|)) とし、ほかの2チャネルは0。
この丸めも BigInt の整数演算で行うため、巨大なラベルを浮動小数点に変換しない。
8ビットの丸めで区別できなくなった非常に大きい値は黒となる。画面内の最大値などで正規化しないため、パンしても同じ値の色は不変。
q=0 は正負のいずれでもなく、湖の表示がONなら水色、OFFなら背景色とする。
この配色は表示用であり、Qの値・判別式・井戸/川/湖の数学的判定を変更しない。
